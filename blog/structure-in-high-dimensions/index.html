Adaptive control

When structure matters more than dimension

Why the way we represent uncertainty matters when an adaptive system has many unknown parameters.

Many parameters, useful structure

A model can contain many unknown parameters without every parameter being equally important. Sparsity and other structural constraints offer information that a learning algorithm can use.

Choosing the geometry of an update

Mirror descent provides a way to design updates around that structure. My work on high-dimensional discrete-time adaptive control investigates how this choice affects transient performance and convergence.

A systems perspective

The objective is more than estimating parameters accurately: the controlled system must behave well while learning takes place. This makes the interaction between estimation, feedback and uncertainty central to the analysis. Any transfer to a particular application also needs its own modeling and validation.
